# landing 技能包

落地：landing(obs) 提供伸腿接地与接地后保持的姿态。需要自行判断下降高度、速度和切换时机；过早伸腿可能提前触地，过晚可能后坐。该姿态是可修改参考，不能保证所有入射姿态更好。落地后新后方触地仍扣距离，触沙后力矩只有原来的35%。

适用身体 trial_old60_k0；不是完整跳远控制器。将需要的函数与常量复制到 bots/bot.py，不能在正式bot中 import 技能包。8项输出顺序与规则相同。可以修改、融合或弃用，不保证换起点或连接自己的控制器就成功。仅有本环节代码，其他环节由你实现。

接口示例：在下降时调用landing(obs)，不要上升阶段就接管。主持方以vy<-1.5且躯干y<2.0接入某套收腿参考动作，5种风均有分，但中位距离下降；这不是推荐固定阈值。请用自己的原版和修改版同种子配对比较，调整接管高度/速度或修改姿态，变差就回退。
