# 常见问题

## 为什么每个人的开发时间一样，结果差这么多？

时间一样，条件并不完全一样：接入通道（Codex / Claude / OpenCode / Qoder / CodeBuddy…）、工具链、上下文长度、模型版本都不同。**这是一个 16 个样本、每个样本只跑一次的娱乐性比赛**，排名不能当成模型能力的严谨评测。

## 仓库里的代码就是最终提交的那一份吗？

是。每人只保留最终提交的 `bot.py`，一份一个目录，哈希写在 `results/bots_manifest.json` 里，你可以逐字节核对。中途版本、未采用的尝试、赛后试验都没有进仓库——**只放能对上榜单的那一份**。

## 成绩为什么可以被验证？

第 1 期的物理没有随机事件，随机种子固定，所以同一份 `bot.py` 在任何机器上跑出来的距离、冲线时间都一样。`verify.py` 把 22 份代码重跑一遍，和榜单逐项比对。

第 2 期每一跳的风是**随机抽**的，但抽到的种子写在成绩文件里；`verify.py` 按记录的种子逐跳重放，所以结果同样可复现。

第 3 期是回合制，每局的初始地形和全部动作都记录在回放里，`verify.mjs` 逐事件重算，比对总杆。个别洞的成绩以裁判记录为准（回放保留的是当时的过程），`verify.mjs` 对这类洞只校验回放本身能否重放。

## 我能拿这些 bot 做别的事吗？

代码 MIT，随便用。但请注意：

- 它们是**为这一条赛道、这一套接口**写的，换赛道、换身体参数就会失效。
- 里面有不少是「卡 bug 式」的怪招（趴着蹬腿、装死、斜着跑），不保证在别的物理引擎里还能跑。
- 立绘、配音、视频不在仓库里，版权不在 MIT 范围内。

## 为什么仓库里没有立绘？

立绘、头像、Q 版表情是生成模型出的同人图，画的是各家模型的拟人形象，会牵扯到别人模型的名称和视觉标识。**这类素材不适合跟着代码一起开源**，所以仓库里一张都没有。

不影响使用：渲染器找不到 `assets/avatars/` 会自动回退成程序绘制的火柴人，动作、镜头、成绩完全一致。想看视频里那个样子，自己准备一套放进去即可。

## 为什么仓库里没有视频？

成片动辄几百 MB 到几 GB，放进 git 会把仓库拖垮。仓库给的是**逐帧姿态 trace + 浏览器播放器 + 官方渲染器**：想看就用 `viewer.html`（轻量、可拖进度），想要成片就用 `engine/visualizer.py` 本地渲染 mp4（1080p、慢动作、游戏风 UI 都支持）。成片链接见各期 README。

## 为什么 `bots/` 里有些代码看起来很糙？

原样收录。选手在限时内写完就交，没有重构、没有整理注释，甚至有调试用的 `print`（仓库里的验证脚本会吞掉这些输出）。要看的是「45 分钟内能做到什么」，不是「代码写得多漂亮」。
