# 开源范围

这个仓库的目标是：**让任何人都能独立复现比赛、验证成绩、参与挑战**。所以「比赛必需的东西」全部公开，「叙事素材」和「内部工具」不公开。

## 公开

| 内容 | 说明 |
|---|---|
| 裁判引擎 | 每期的 `engine/`，包括物理、计分、倒地判定，附 SHA256 |
| 任务包 | 当时发给 AI 的 `PROMPT.md` / `TASK.md`、模板、技能包、公开 SDK |
| 选手代码 | 每位模型最终提交的那一份，原样 |
| 成绩 | 逐人成绩、逐跳/逐局明细、名次与积分 |
| 验证脚本 | `verify.py` / `verify.mjs`，重跑并与榜单比对 |
| 回放 | 第 1、2 期的逐帧 trace + 播放器；第 3 期的全部 324 份回放 + 静态观战器 |
| 投稿与榜单 | `community/`，观众 bot 与观众榜 |

## 不公开

| 内容 | 原因 |
|---|---|
| 成片、角色立绘、Live2D、配音、BGM | 立绘是生成模型出的同人形象，涉及其它模型的名称与形象，出于版权考虑不上传；成片体积大，视频见 B 站 |
| 内部调度器与选手工作区镜像 | 含本机路径、账号、额度信息；只保留任务书与最终代码 |
| 隐藏参数与未采用的数值实验 | 第 3 期的部分弹道/落地系数属于比赛隐藏信息 |
| 未采用的中间版本 | `*.pre_*.py`、`snapshots/`、`_backup/`；避免与榜单对不上 |
| 逐条运行日志与 token 账单 | 含通道细节；必要结论写进 `docs/faq.md` |

## 第三方素材

第 1、2 期的角色立绘由生成模型产出、经人工挑选；第 3 期美术来自项目美工素材库。**这些素材不在本仓库内**，也不在 MIT 许可范围内。如果你的项目里要复用，请自行确认授权。

字体同理：视频里用过的一些字体商用需要授权，仓库里的回放页面只用系统字体。

## 引用

如果要在文章或视频里引用成绩，请带上名次口径（见 [`scoring.md`](scoring.md)）。只引用「第 1 名是谁」而不说口径，很容易被误读成模型能力排名。
